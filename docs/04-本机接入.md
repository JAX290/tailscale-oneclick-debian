# 04 · 本机接入（Windows / macOS / Linux）

服务器收口后只有 tailnet 能进，所以**你自己的电脑必须先加入同一个 tailnet**。

## 安装客户端

### Windows

```powershell
winget install --id Tailscale.Tailscale -e
```

装完从开始菜单打开 Tailscale，登录你的账号（浏览器 SSO）。
CLI 在 `C:\Program Files\Tailscale\tailscale.exe`，可以加进 PATH：

```powershell
$env:Path += ";C:\Program Files\Tailscale"
tailscale status
```

### macOS

```bash
brew install --cask tailscale
```

或从 App Store 安装。登录后菜单栏出现 Tailscale 图标。

### Linux

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

## 把你的电脑打成 `tag:agent`

ACL 里 `src` 写的是 `tag:agent`，所以这台电脑必须带这个标签：

```bash
tailscale up --advertise-tags=tag:agent --reset
```

或者在控制台 Machines → 设备 → Edit tags 手动加。

> 打标签后这台设备不再属于"你的个人设备"，权限完全由 ACL 决定 —— 这正是"最小权限"想要的。
> 副作用：它不能再享受默认的"全通"特权，别的东西也要靠 ACL 放行。

## 登录服务器

```bash
# 方式一：Tailscale 自带封装（推荐，会自动处理一些细节）
tailscale ssh opsagent@web1

# 方式二：普通 ssh（Tailscale SSH 会接管 tailnet 内的 22 端口）
ssh opsagent@web1
ssh opsagent@100.x.y.z
```

主机名来自 MagicDNS（默认开启）。如果解析不到，就用 `tailscale status` 里的 `100.x` 地址。

### 可选的 ssh 别名

`~/.ssh/config`：

```
Host web1
    HostName web1
    User opsagent
    # 走 Tailscale 后不再需要 IdentityFile
    ServerAliveInterval 30
```

之后 `ssh web1` 即可。

## 验证连接链路

```bash
tailscale status            # 两台设备都是 online
tailscale ping web1         # 直连还是 DERP 中继
ssh opsagent@web1 'id; hostname'
ssh opsagent@web1 sudo ops-status | head -n 20
```

## 关于 AI 助手（agent）接入

如果你要让 AI 帮你在这台服务器上干活：

1. **让 AI 用 `opsagent`，不要用 root。** 它执行的是 `ssh opsagent@web1 sudo ops-status` 这种命令。
2. **本机侧保留人工批准**：DSH 的沙箱默认不允许联网，每次 `ssh` 都需要你批准一次
   （`danger-full-access` 一次性授权）。这是一道很好的人工闸门，别关掉。
3. **给 AI 用的设备单独打 `tag:agent`**，ACL 只放行到 `tag:server:22`。
   即使这台电脑被入侵，攻击者也只能摸到服务器的 22 端口，且只能以 `opsagent` 登录。
4. **不要让 AI 直接改 ACL / sshd / sudoers**。这四样（`sshd_config`、防火墙、`sudoers`、`authorized_keys`）
   永远人手动改。

## 常见问题

| 现象 | 处理 |
|---|---|
| `tailscale status` 里服务器 offline | 服务器 `systemctl status tailscaled`；或 key expiry 到期（控制台关掉） |
| `tailscale ssh` 提示 no matching rule | 本机没打 `tag:agent`，或 ACL 的 `src` 写错 |
| `ssh` 提示 Permission denied (publickey) | 走的是 sshd 而不是 Tailscale SSH：检查服务器 sshd 是否已收口、ACL 是否有 ssh 规则 |
| 能 ping 通但 22 不通 | ACL 的 `acls` 没放行 `tag:server:22` |
| Windows 上 `tailscale` 命令找不到 | 用完整路径 `& "C:\Program Files\Tailscale\tailscale.exe"` |
| 连接被 DERP 中继很慢 | `tailscale ping web1` 看是否 direct；NAT 严格时属正常 |
| known_hosts 冲突 | `ssh-keygen -R web1`（Tailscale SSH 的 host key 可能与旧 sshd 不同） |
